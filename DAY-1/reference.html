Uses of Inline Test Elements:

1. p :

<p> tag represents a paragraph.Paragraphs are usualy represented in visual media as blocks of text seperated from adjacent blocks by blank lines and / or frist line intendation,but HTML paragraphs can be structural grouping of relative content , such as images or form fields.

eg:<p> This is a paragraph </p>

2. span :

<span> tag is a generic inline container for phrasing content,which does not inherently represent anything. It can be used tp group elements for styling purposes using the class or id attributes.

eg:<p> here is the example <span style="color:blue">blue</span> for span</p>

3. strong :

<strong> indicates that its contents have strong importance, seriousness or urgency.

eg:<strong> This text is important </strong>

4. em :

<em> is used to mark the text that has stress emphasis

<p>Come <em>Fast!</em> </p>

5. small :

<small> represents side comments and small print like copyright and legal text.By default ,it renders text withim it one font size smaller.

eg: <p><small> This is smaller Text </small> </p>

6. b :

&lyb> specifies bold text to draw user's attention without any extra importance to the text

eg: <p><b> This is bold Text </b> </p>

7. i :

<i> used to represent a range of text that is set off from the normal text for some reason, such as idiomatic text,technical terms, and taxonomical designations.

eg: <p>The<i> RMS Titanic </i> is a streamship </p>

8. u :

<u> represents some text that is unarticulated and styled differently from normal text,The content inside is typically displayed with an underline.

eg: <p>This is some<u> misplaced </u> text </p>

9. s :

<s> represents text that is no longer correct ,accurate or relevant.The text will displayed with a line through it.
eg:
<p><s> 10 tasks completed </s></p>
<p> 15 tasks completed! </p>

10. sup :

<sup> defines superscript text,that appears half a character above the normal line,and is sometimes rendered in a smaller font.

eg: <p>equation is a<sup>2</sup> + b<sup>2</sup></p>

11. sub :

<sub> defines subscript text,that appears half a character below the normal line,and is sometimes rendered in a smaller font.

eg: <p>equation is H<sub>2</sub>>O<sub>2</sub></p>

12. abbr :

<abbr> defines an abbreviation or an acronym,like "HTML","CSS".

eg: The <abbr title="World Health Organization">WHO</abbr> was founded in 1948.

13. cite :

<cite> is used to mark up the title of creative work

eg: <p><cite>The Scream</cite> by edward Munch was painted in 1893.<p>

14. q :

<q> element indicates that the enclosed text is a shorter inline quotation

eg: <p>WWF's goal is to:<q>Build a future where people live in harmony with nature.</q>We hope they succeed.</p>

15. code :

<code> element displays its contents styled in a fashion intended to indicate that the text is short fragment of code.
eg:
<p>The<code>push()</code>method adds one or more elements to end of an array and return the new length of the array.</p>

16. kbd :

<kbd> is used to represent keyboard input or keyboard shortcuts.It displays text in a way that indicates the user should press a key or combination of keys.
eg:
<p>Open a new windows using the keyboard shortcut<kbd>Ctrl</kbd> + <kbd>N</kbd></p>

17. samp :

<samp> is used to define sample output from a computer program.
eg:
<p>Message from my computer:<kbd>Ctrl</kbd> + <kbd>N</kbd></p>

18. var :

<var> is used to define a variable in programming or in mathematical expression.
eg:
<p>The area of a triangle is : 1/2 *<var>b</var> * <var>h</var> </p>

18. mark :

<mark> defines text that should be marked or highlighted.
eg:
<p>Do not forget to buy <mark>milk</mark> today </p>

19. del :

<del> represents a range of text that has been deleted from a document
eg:
<p>My favourite color is <del>blue</del></p>

20. ins :

<ins> represents a range of text that has been added to a document.
eg:
<p>My favourite color is <del>blue</del> <ins>red</ins>!</p>

21. time :

<time> represents a specific period in time.It may include the datetime attribute to translate dates into machine readable format
eg:
<p>store is open from <time> 10:00 </time> everyday</p>

22. dfn :

<dfn> stands for the "definition element",and it specifies a term that is going to be defined within the content .
eg:
<p><>HTML</dfn> is the standard markup language for creating web pages</p>
